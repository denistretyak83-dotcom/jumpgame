# ДОКУМЕНТ 3 — `docs/AUDIT_GRAPHICS.md`

# Аудит графики (вне архитектурного кода)

Оценка (после ФР-1..4): ≈ 7-8/10.

## Сделано
- SpriteSource контракт + PNG и procedural источники (OCP-реестр).
- ProceduralPixelArt: ASCII-спрайты героя/врагов + фигуры монет/тайлов.
- Автотайлинг платформ (_neighbor_mask + _draw_edges).
- ParallaxBackground: контракт Background + многослойный темиезированный фон.

## Осталось
- ФР-5: squash&stretch анимации.
- Полная интеграция procedural во все уровни (сейчас переключается флагом).
- Возможный procedural-фон (генерация слоёв, а не фиксированные полигоны).

## Примечание
- Архитектура (ООП/MVC/SOLID) позволяет добавлять графику БЕЗ правки модели —
  весь арт-пайплайн в View-слое. Это ключевое преимущество после Фаз 1-13.
