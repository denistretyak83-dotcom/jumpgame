## 2. Суть проекта

**Игра:** «Jump & Reach the Flag» — 2D-платформер на **Python + Pygame**. Игрок прыгает по платформам, собирает монеты, избегает врагов и достигает флага.

**Архитектура (заявленная и целевая):**

- **MVC** с разделением Model / View / Controller.
- **MVC с DTO:** модель отдаёт чистые данные `ModelVisualData` (без pygame); View превращает их в кадры через цепочку `get_visual_data() -> build_state() -> render()`; Controller — единственный читатель ввода.
- **EventBus (Observer):** токенизированная подписка с изоляцией ошибок; все события — константы `GameEvents.*`.
- **Data-Driven уровни из JSON** (`levels/*.json`) через `LevelManager`/`LevelBuilder`.
- **Полный DI:** `Settings` и `GameLogger` инжектируются через конструкторы; точка создания — `main.py` (`Settings() -> GameLogger(config=logging) -> Game(config, logger)`).
- **Отказ от глобалов и синглтонов.**
- **SOLID / OCP:** новый тип объекта/вью/поведения/состояния — регистрация через реестры, а не модификация существующих классов.

**Ключевое ограничение (непоколебимое):** **_игра работает и должна продолжать работать_**. Все правки — поэтапно, маленькими PR, под юнит-тестами, без рискованных одномоментных изменений.

**Пакеты:** `models/`, `views/`, `controllers/`, `core/`, `levels/`, `audio/`, `config/`, `main.py`, `requirements.txt`.

| Проблема | Файл | Детали |
